How to read the two columns

Left: histogram of each layer's outputs for a batch of 32 random Gaussian inputs (mean 0, variance 1), at initialization, before any training. Right: size of the gradient that reaches each layer on the backward pass (the derivative of the loss with respect to that layer's output), divided by the same quantity for the last layer. The dashed line is "same as the last layer"; bars stop at 3 times, and » marks more. The loss is the squared size of the final output; biases are 0.

    How this is built

    Both networks see the same 200 points, the same batches and the same random seed. Plain layer: act(BN(W h + b)). Residual layer: h + W act(BN(h)) + b, a pre-activation block (the form used in the prototype). BatchNorm uses batch statistics while training and running statistics for the decision map. Xavier init for tanh and sigmoid, He init for ReLU; residual branches start at 0.1 times that scale. The gradient strip shows the size of the gradient reaching each layer, relative to the last layer. SGD with momentum 0.9, softmax cross-entropy, hand-written backprop.
